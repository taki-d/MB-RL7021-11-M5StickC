# 本体表示の改善（2026-10-07）

M5StickCPlusライブラリの横向き240×135画面を対象に、電力値だけの表示を更新した。
電流OFF、電力の最小要求間隔1秒、積算値30分の設定は変更していない。

## 表示内容

- 電力値を中央に大きく表示。桁数・符号に合わせてフォントを切り替え、Wを含めて画面内に収める。
- 取得前は `-- W`。まだ受信していない値を0Wとして表示しない。
- 上部の `WIFI` と点は、Wi-Fi接続中なら淡色／緑、未接続なら赤。
  これはメーターの接続状態とは独立している。
- `CONNECT`: メーターの接続処理中。中央下にスキャンなどの処理段階を表示する。
- `WAIT`: 接続済みで最初の電力応答を待っている。
- `LIVE`: 最終受信から5秒未満。
- `DELAY`: 5秒以上10秒未満。電力値も橙色にする。
- `STALE`: 10秒以上。電力値を消さずに赤で残し、古い値だと分かるようにする。
- `OFF`: 電力メトリクスの取得が無効。
- `RX`: 最後の電力サンプルを受信してからの経過時間。
- `DT`: 直近2サンプルの受信間隔。同じW値が続いても受信ごとに更新する。

RX/DTはメーター内部の測定時刻ではなく、本体で受信した時刻に基づく。
年齢表示・状態表示は約1秒ごとに更新し、新サンプルはその都度反映する。
同じW値の継続と返信停止を区別できる。

## 推移グラフ

下部は直近2分を固定した時間軸で表示する。最大64サンプルをRAMに保存し、
縦軸は自動調整する。右上はこの区間の実サンプルの最小値・最大値（W）。
値が一定でも計算が破綻しないよう、縦軸には余白を設けている。

サンプル間隔が10秒以上空いた場所では線をつながない。
欠測を等間隔のデータや補間した値として描かない。履歴は再起動で消える。
表示用の追加要求は送信しない。

## 描画と取得の分離

`firmware/src/meter_display.h/.cpp` に描画を分離した。
240×135×2バイト（約65KB）の16bitスプライトを起動時に一度だけ確保する。
画面全体はこのRAM上で組み立て、前回と内容が異なる16行単位の帯だけLCDへ転送する。
1回の `loop()` では最大1帯を転送し、その間にもUARTの受信処理に戻る。
前の画面の転送が終わるまでバッファを次の画面で上書きしない。

LCD全体の消去は起動時のみ。毎サンプルの黒画面を挟む更新はしない。
画面バッファの確保に失敗した場合はエラー表示を残し、計測とHTTPは継続する。
描画処理はHTTPコールバックから呼び出さない。

## 確認結果

- PlatformIOのビルド・実機書き込み成功。
- 起動ログで `DISPLAY ready heap=235636` を確認。画面バッファ確保成功後、
  Wi-Fi起動前の空きヒープは約235KBだった。
- 起動から180秒の実機計測で電力66応答・66サンプル。タイムアウト0回。
- 先頭40秒の接続・初期積算取得を除いた区間では、電力61サンプル、
  受信間隔の中央値2.399秒、P95 2.404秒、最大2.412秒。
- 全区間の最大3.8秒は初期の単位取得を挟んだ間隔だった。
- 要求中の `loop()` 呼び出し間隔の最大値は21ms。
  前回の電流OFF試験では47msだった。これらは描画だけの所要時間ではなく、
  Wi-Fi等も含む処理間隔の実測値。今回の範囲では取得周期の悪化は見られなかった。
- `/metrics` と `/healthz` を確認。電流メトリクスは無効のまま。
- ホスト上で、実装と同じ描画コード／M5ライブラリのフォントを使った
  通常・接続中・STALE・一定値のプレビューを生成し、レイアウトを目視確認した。
  本体LCDを撮影したものではないため、物理画面の輝度や見え方までは未確認。

実機ログ: `/tmp/m5-display-validation-20261007.jsonl`（一時ファイル）。

## テストの再実行

リポジトリのルートから実行する。ホスト表示テストはPlatformIOが配置した
M5StickCPlusのフォントを参照するため、先に通常ビルドを済ませる。

```sh
/Users/taki/.platformio/penv/bin/pio run -d firmware -e m5stick-c
c++ -std=c++11 -Wall -Wextra \
  -I tests/display -I firmware/src \
  -I firmware/.pio/libdeps/m5stick-c/M5StickCPlus/src \
  tests/display/test_display.cpp firmware/src/meter_display.cpp \
  -o /tmp/m5-display-host-test
/tmp/m5-display-host-test
```

未取得・接続待ち・LIVE/DELAY/STALE・取得OFF、値の桁数と負数、
INT32の上限下限、履歴リングの周回、一定値、`millis()` の周回、
バッファ確保失敗、画面外への描画、帯ごとの転送を検証する。

プレビュー画像も必要な場合は、新しい出力ディレクトリを渡す。

```sh
display_preview_dir=$(mktemp -d /tmp/m5-display-preview.XXXXXX)
/tmp/m5-display-host-test "$display_preview_dir"
# macOSではPPMをPNGに変換できる。
sips -s format png "$display_preview_dir/live.ppm" --out "$display_preview_dir/live.png"
```
